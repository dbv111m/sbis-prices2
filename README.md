# Скрапер тарифов saby.ru

Сбор тарифов saby.ru по регионам России (все 20 вкладок тарифов), отчёты
CSV/Excel с человекочитаемыми названиями услуг, анализ ценовых зон и
кластеров регионов. Все находки и инсайты по скрапингу собраны в
[INSIGHTS.md](INSIGHTS.md).

## 🚀 Установка (Windows)

```bash
git clone https://github.com/dbv111m/sbis-prices2.git
cd sbis-prices2
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install          # только для Playwright-fallback скрапера
```

## 🏗 Архитектура

| Скрипт | Назначение | Скорость |
|---|---|---|
| `http_scraper.py` | **Основной скрапер**: чистый HTTP, без браузера (цены вшиты в серверный HTML) | ~1 сек/регион, вкладка за ~2 мин |
| `optimized_scraper.py` | **Fallback-скрапер** (Playwright), если сайт начнёт блокировать HTTP | ~10 сек/регион, вкладка за ~12 мин |
| `generate_reports.py` | Отчёты: CSV (плоский) + Excel (секции по группам) | секунды |
| `analyze_prices.py` | Анализ: единые/региональные цены, кластеры регионов | секунды |

Оба скрапера пишут **идентичный формат** JSON и взаимозаменяемы.
Стратегия надёжности: работаем через `http_scraper.py`; при признаках
блокировки (пустые ответы, страница диагностики) — переходим на
`optimized_scraper.py` (см. раздел «Надёжность»).

## ⚙️ Использование

### 1. Скрапинг (HTTP, основной способ)

```bash
python http_scraper.py --tab edo                      # все 90 регионов, ~2 мин
python http_scraper.py --tab staff --regions 77,78,05 # выбранные регионы
python http_scraper.py --tab retail --limit 2         # тест: первые 2 региона
python http_scraper.py --tab edo --output my.json     # свой файл вывода
```

### 2. Скрапинг (Playwright, fallback)

```bash
python optimized_scraper.py --tab edo            # headless-браузер
python optimized_scraper.py --tab edo --visible  # показать окно (отладка)
```

Общие параметры обоих скраперов: `--tab`, `--regions 77,78`, `--limit N`,
`--max-retries N`, `--output`, `--regions-file`. Выход:
`{tab}_optimized_scraped_data.json` (90 регионов × услуги).

### 3. Отчёты

```bash
python generate_reports.py --input edo_optimized_scraped_data.json
# -> edo_nomenclature_prices_report.csv / .xlsx
```

- **CSV** — плоская таблица `Группа | Услуга | Код | регионы`, сортировка по группам;
- **Excel** — лист с секциями-заголовками по группам, закреплённой шапкой.

### 4. Анализ цен и кластеров

```bash
python analyze_prices.py                             # сводка по всем вкладкам
python analyze_prices.py --input edo_optimized_scraped_data.json
python analyze_prices.py --save-clusters region_clusters.json
```

## 🏷 Названия услуг и группы (nomenclature_map.json)

Технические коды (`EOpSBISfrmIoN`, `ETRN_50000`...) малопонятны, поэтому:

1. **Playwright-скрапер** автоматически сохраняет название услуги с сайта (поле `name`);
   HTTP-скрапер этого не делает — названия берутся из mapping;
2. **`nomenclature_map.json`** — редактируемый словарь: `name` (человекочитаемое имя),
   `group` (группа) для каждого кода + `group_order` (порядок групп).

Приоритет названия: **mapping → имя с сайта → код**. Незнакомые коды попадают
в группу «Прочее» — достаточно дополнить словарь.

## 🔬 Инсайты о ценообразовании (по данным скрапа 22.09.2026)

Полный разбор — в [INSIGHTS.md](INSIGHTS.md). Кратко:

- **72% услуг (54 из 75 на 3 вкладках) имеют единую цену по всей стране**;
- **Региональное ценообразование сосредоточено в планах отчётности**
  (`EOpSBISfrm*`): 9–13 ценовых уровней, разброс до 4–5 раз;
- Устойчивые **ценовые зоны**: Чувашия — почти всегда минимум; Москва и МО
  (идут парой) — всегда максимум; ХМАО — отдельная дорогая зона в «Корпоративном»;
- **Кластеры регионов** с идентичными ценами на все услуги (region_clusters.json):
  «Обмен данными» — 1 кластер (все 90 регионов!), «ЭДО» — 3 кластера,
  «Отчётность» — 76 (региональные планы делают регионы почти уникальными).

## 🛡 Надёжность (если что-то заблокируют)

1. **HTTP-скрапер** — быстрый основной путь. Использует современный User-Agent
   (Chrome 138–140): со старыми UA (Chrome ≤109) сайт редиректит на страницу
   «Диагностика рабочего места» — это уже учтено;
2. **Playwright-скрапер** — полный fallback: реальный браузер, случайные UA/
   viewport, случайные паузы, retry. Если и он блокируется — раскомментируйте
   настройку прокси в начале `parse_nomenclature_prices`;
3. Оба скрапера пишут одинаковый JSON — остальные скрипты не зависят от того,
   каким способом собраны данные.

## 📁 Структура проекта

- `INSIGHTS.md`: Все находки и инсайты по скрапингу и ценообразованию.
- `http_scraper.py`: Быстрый HTTP-скрапер (основной, без браузера).
- `optimized_scraper.py`: Playwright-скрапер (fallback, собирает имена услуг с сайта).
- `generate_reports.py`: Отчёты CSV/Excel с группами услуг.
- `analyze_prices.py`: Анализ единообразия цен и кластеров регионов.
- `regions.json`: Справочник регионов (90 шт., коды + названия).
- `nomenclature_map.json`: Расшифровка кодов: названия, группы, порядок групп.
- `region_clusters.json`: Карта кластеров регионов с идентичными ценами.
- `{tab}_optimized_scraped_data.json`: Собранные данные по вкладке.
- `{tab}_nomenclature_prices_report.csv/.xlsx`: Отчёты по вкладке.
- `requirements.txt`: Зависимости с зафиксированными версиями.
- `old/`: Устаревшие версии скриптов.
