# Поиск цен в скачанных данных saby.ru

## Быстрый путь

Все данные уже скачаны в репозиторий — сеть не нужна. Из корня репозитория:

```bash
.venv/Scripts/python find_price.py --city <город> --service <услуга>
```

Режимы:

| Запрос | Что вернёт |
|---|---|
| `--city Казань` | все 254 услуги региона (Казань автоподставится как Республика Татарстан) |
| `--service маркировка` | цену услуги по всем регионам: либо «единая цена», либо ценовые уровни |
| `--city СПб --service ЭДО` | точечная цена (все вкладки, где есть совпадение) |
| `--service ЭТрН --tab edo` | только указанная вкладка |

Поиск услуги — по вхождению подстроки (без регистра) в человекочитаемое
название из `nomenclature_map.json`, имя с сайта или техкод
(`"ЭДО — Базовый"`, `маркировк`, `ETRN_50000` — всё сработает).
Город — алиас (Казань, СПб, Екатеринбург...) или подстрока названия региона
(`Татарстан`, `Свердловская`). Цены привязаны к регионам, не к городам.

## Что за данные

- Файлы `{tab}_optimized_scraped_data.json` — 20 вкладок тарифов saby.ru,
  формат `{регион: [{"nomenclature_code", "price", "name"}, ...]}`;
- Срез на 22.09.2026, полный прогон 20×90 = 36 090 записей;
- Расшифровка кодов: `nomenclature_map.json` (254 кода: имя + группа).

## Ключевой инсайт о региональности (обязательно учитывай в ответах)

**Из 254 услуг лишь ~22 зависят от региона, и 20 из них — планы отчётности**
(вкладка ereport, коды `EOpSBISfrm*`). Значит:

- Для 16 из 20 вкладок цена **одинакова во всей стране** — если города
  пользователя нет в списке регионов, цена почти наверняка та же, что и в любом
  другом регионе (искать по любому, например Москве);
- Регионально варьируются: планы отчётности (9–13 уровней, разброс до 4–5 раз),
  «ЭДО — Базовый» (3 зоны), одна услуга «Торговля и производство», плюс
  точечные наценки Москвы и МО (Центробанк, АУСН, корпоративная бухгалтерия);
- **Мониторинг цен:** можно сканировать 17 вкладок по 1 региону + полный проход
  только по отчётности — вся картина за ~5 минут вместо ~45
  (полный HTTP-прогон одной вкладки ≈ 2 мин: `http_scraper.py --tab <tab>`).

## Кластеры регионов (идентичные цены на все услуги)

Полная карта — `region_clusters.json` (76 кластеров на 90 регионов, сводно по
всем вкладкам; пересчёт: `python analyze_prices.py --save-clusters region_clusters.json`).

Многорегиональные кластеры (внутри кластера цены неразличимы — можно
называть цену любого региона):

- Донецкая нар. респ., Запорожская обл., Луганская нар. респ., Херсонская обл.
- Респ. Кабардино-Балкарская, Респ. Карачаево-Черкесская
- Мурманская обл., Республика Карелия
- Республика Татарстан, Саратовская обл.
- Оренбургская обл., Республика Тыва
- Кировская обл., Удмуртская Республика
- Республика Чечня, Ставропольский край
- Архангельская обл., Вологодская обл.
- Волгоградская обл., Костромская обл.
- Камчатский край, Сахалинская обл.
- Самарская обл., Тольятти
- Республика Крым, Севастополь

Особые случаи:

- **Москва и Московская обл.** идут парой почти во всех зональных услугах
  (всегда самый высокий уровень), но в планах отчётности различаются —
  для ereport проверяй конкретный регион;
- Остальные ~64 региона уникальны только из-за планов отчётности (ereport);
  по всем остальным вкладкам они идентичны всей стране;
- Ценовые зоны (для ereport): Чувашия — почти всегда минимум; далее дешёвая
  зона (Архангельская, Вологодская, Астраханская); средняя (Кавказ, юг);
  выше средней (Бурятия, Карелия, Татарстан, Коми, СПб); дорогая
  (Новосибирская, Пермский, Самарская, Иркутская); максимум Москва+МО;
  ХМАО — отдельная дорогая зона в «Корпоративном».

## Если данных не хватает

- Нужна вкладка или регион, которых нет в данных → практически исключено
  (собраны все 20×90), но при необходимости: `python http_scraper.py --tab <tab> [--regions 77,78]` (~1 сек/регион);
- Данные устарели (цены могли измениться) → перезапусти нужную вкладку
  HTTP-скрапером и сверь через `python analyze_prices.py --input <файл>`;
- Подробности устройства сайта и все находки — `INSIGHTS.md` в корне.
